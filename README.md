# MoviesAdmin

## Overview

MoviesAdmin is the administration module for a movie review platform inspired by Rotten Tomatoes. This application enables administrators to manage movie information through CRUD (Create, Read, Update, Delete) functionality.

## Features

### Movie Management (CRUD)

- Create new movie records
- View a list of all movies
- View detailed movie information
- Update existing movie records
- Delete movie records

### Movie Attributes

Each movie record may include:

- Title
- Description / Synopsis
- Release Date
- Genre
- Runtime
- Director
- Cast
- Poster Image URL
- Trailer URL
- Rating Classification
